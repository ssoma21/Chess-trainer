# Chess Trainer v1.1

Offline chess opening trainer with Stockfish, adaptive puzzles and a blunder detective.

**New in v1.1**
- Play vs computer with Stockfish and an adjustable Elo (800 to Max)
- Adaptive puzzle rating (275 puzzles)
- Blunder detective: import a chess.com game or paste a PGN
- Windows installer, Android APK and iPhone home-screen app

**Files**
- `chess-trainer-offline.html`: open in any browser
- `ChessTrainer-Setup.exe`: Windows installer (unsigned; SmartScreen will warn, choose "Run anyway")
- `ChessTrainer.apk`: Android 5.0+ (signed with a self-made key; Play Protect may warn)
- `ChessTrainer-iPhone-PWA.zip`: host over https, then Safari > Share > Add to Home Screen
