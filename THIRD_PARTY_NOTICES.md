## Stockfish and the GPL

The chess engine is Stockfish, licensed under the GNU General Public License v3.0. The single-file builds
(`chess-trainer-offline.html`, the Windows installer, the Android APK and the iPhone web app) embed the unmodified
Stockfish.js engine, so **those combined builds are distributed under the terms of the GPL-3.0 for the Stockfish part**.
The MIT-licensed code in this repository is GPL-compatible. If you redistribute a build, you must keep the GPL notices and
make the corresponding source available. The engine source is available from the upstream projects linked above
(the `stockfish` npm package, version 11.0.0, contains the sources), and the rest of the source is this repository.

## Data

- Opening lines are standard, widely published opening theory.
- The puzzles in `data/puzzles.json` were generated by this project: positions from engine-played games, each checked with
  Stockfish to have one clearly best move. Puzzle ratings are estimates. The mining tools use
  [python-chess](https://github.com/niklasf/python-chess) (GPL-3.0) as a development tool; it is not part of any build.
- The chess.com import calls chess.com's public API at runtime. Chess.com is not affiliated with this project.
